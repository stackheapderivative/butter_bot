# Butter Bot

## What is this?
Butter bot is an extremely sophisticated and extreme user experience that is meant to upend society and create a more perfect and glistening world wherein any user can request some butter and humbly receive their golden butter snack to feast upon like a bar of chocolate. The butter bot will use computer vision to locate a stick of butter, drive itself to the stick of butter, pick it up, and gracefully like an angel, deliver it to the user.
